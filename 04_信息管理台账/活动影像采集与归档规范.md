# 活动影像采集与归档规范（作品集示例）

> 本规范用于展示活动宣传资料管理思路。实际执行须以园所制度、监护人授权范围及集团要求为准。

## 一、采集前确认

- [ ] 活动名称、日期、地点、负责人已确认
- [ ] 已明确拍摄用途：内部留档 / 家园沟通 / 公众号 / 视频号 / 其他
- [ ] 已核对儿童及教职工影像授权状态和使用范围
- [ ] 已确认不拍摄或不公开的人员、区域、信息
- [ ] 已准备拍摄清单，避免只拍合影、忽略活动过程
- [ ] 已指定素材接收人和存储位置

## 二、拍摄清单

| 场景 | 建议画面 | 注意事项 |
|---|---|---|
| 活动环境 | 场地布置、材料、作品展示 | 检查画面中的姓名牌、班级名单等信息 |
| 活动过程 | 操作步骤、师幼互动、材料使用 | 以活动记录为主，不摆拍、不影响教学 |
| 活动成果 | 作品、过程记录、集体成果 | 不擅自将个别儿童成果包装为全体成果 |
| 教师支持 | 教师示范、引导材料 | 拍摄前确认授权及使用边界 |
| 收尾整理 | 材料归位、环境恢复 | 可用于体现活动完整流程 |

## 三、文件命名规则

建议格式：

`YYYYMMDD_园区_活动简称_场景_序号_授权状态.扩展名`

示例（虚构命名，仅说明格式）：

`20261102_示例园区_秋日观察_材料准备_001_内部授权.jpg`

不要把儿童姓名、身份证号、家庭联系方式等写入文件名。

## 四、目录结构建议

```text
活动影像/
└── 2026/
    └── 2026-11/
        └── 20261102_活动简称/
            ├── 01_原始素材/
            ├── 02_筛选素材/
            ├── 03_已审核发布/
            └── 04_授权与审核记录/
```

## 五、筛选、发布与归档

1. 原始素材只由授权人员访问，避免在个人社交账号或无关群聊中传播。
2. 筛选时检查清晰度、构图、活动事实、背景信息和授权状态。
3. 对外发布前再次核对人物授权、文字事实、日期、园所名称和图片说明。
4. 原始素材与发布成品分开保存；保留必要的审核记录和版本信息。
5. 按园所规定设置访问权限、保存期限和删除流程，不自行长期保留儿童影像。

## 六、归档登记

| 活动日期 | 活动名称 | 素材数量 | 授权核验 | 审核人 | 发布渠道 | 归档路径 | 访问权限 |
|---|---|---:|---|---|---|---|---|
| | | | 待核验/已核验 | | | | |

## 七、隐私红线

- 未取得适当授权，不对外发布可识别儿童的照片、视频或个人信息。
- 不公开儿童名单、联系方式、健康信息、接送信息、家庭住址等。
- 不把未经审核的原始素材上传到公开网盘、公开仓库或公开作品集。
- 作品集展示优先使用自制图形、空白模板、虚构数据或经过充分匿名化的素材。
