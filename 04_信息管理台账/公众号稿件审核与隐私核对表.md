## 二、事实与文字核对

- [ ] 园所、部门、班级名称准确
- [ ] 活动时间、地点、参与范围准确
- [ ] 活动内容与实际记录一致，没有虚构成果或夸大表述
- [ ] 人名、职务、引用内容已核实
- [ ] 错别字、标点、数字、单位已检查
- [ ] 标题准确，不使用绝对化、夸张或误导性表述
- [ ] 图片说明与画面内容一致
- [ ] 已由活动负责人确认事实信息

## 三、个人信息与影像授权核对

- [ ] 图片/视频中的可识别人员已完成授权核验
- [ ] 授权用途覆盖本次拟发布渠道和使用场景
- [ ] 未授权人员已避开、替换或做适当处理
- [ ] 画面中没有儿童姓名牌、名单、联系方式、接送信息
- [ ] 没有健康信息、家庭信息、定位轨迹等不必要个人信息
- [ ] 图片元数据及背景内容不存在不必要的隐私暴露
- [ ] 没有使用来源不明、未经许可的网络图片或音乐

## 四、版式与技术检查

- [ ] 手机端预览标题、正文、图片均清晰
- [ ] 图片比例统一，关键内容没有被裁切
- [ ] 字号、行距、段落间距适合移动端阅读
- [ ] 封面图与文章主题一致
- [ ] 链接、二维码、菜单跳转可用
- [ ] 无错图、重复图、模糊图或未替换占位图
- [ ] 发布预览与最终审核版本一致
