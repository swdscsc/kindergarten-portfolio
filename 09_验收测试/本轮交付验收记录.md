## 三条视频规格

- `01_编辑部纪实风.mp4`：12 秒，H.264，720×1280，24fps。
- `02_路径信息图风.mp4`：12 秒，H.264，720×1280，24fps。
- `03_清单排版风.mp4`：12 秒，H.264，720×1280，24fps。

视频均为原创平面动态图形和中文排版，静音字幕版，明确标注模拟演示，不使用儿童 AI 人像冒充真实拍摄。

## MP4 文件与 GitHub 的边界

高画质 MP4 由本次对话作为独立文件交付。GitHub 仓库已保存可复现生成脚本、分镜说明和成片目录说明，但本轮没有把 MP4 二进制本体提交到仓库。下载后放入 `03_宣传视频/成片/` 即可本地归档和运行验收。

## 复测方式

```bash
pip install Pillow
python 03_宣传视频/视频生成脚本.py
python 09_验收测试/run_tests.py
python 09_验收测试/run_tests.py --json
```

若成片已放入 `03_宣传视频/成片/`，验收脚本会尝试用 ffprobe 检查编码、时长与画幅。
