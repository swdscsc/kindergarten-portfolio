## 二、正文结构（全文拆解）

```
导语（目的+意义式，1 段）
  句式：为进一步强化/增强……，提升/掌握……，筑牢园所安全防线，X月X日，XX幼儿园开展了……
主体（3–5 个小标题分段，小标题=四字/八字短句，实际是图片的图下配字）
  过程套话：有序排队 / 快速而有序 / 紧张有序、规范高效 / 无一名幼儿遗漏
意义升华（1 段）
  句式：不仅检验了……更让师幼在亲身体验中掌握了……
结尾承诺式（1 句）
  句式：将持续把安全工作放在首位，定期开展各类安全演练活动，为孩子们的健康成长保驾护航！
```

**两种体例要分清**：上表是"活动简讯体"（无家园共育板块）；"知识普及型"推文则会在结尾加安全知识清单+家园共育倡议。本作品集图文稿采用"简讯体为主体 + 结尾附一条家园共育小贴士"的混合式，兼顾规范与实用。

## 三、排版规范（135 编辑器幼儿园指南）

- **封面**：头条 900×383px（2.35:1）；正文配图宽 100%，导出宽约 1080px。
- **字号**：正文 15–16px；小标题 18–20px（不超过 20px）；行间距 1.75–2.0；段间距 15–20px。
- **配色**：日常温馨（粉）、通知类（蓝）、节日活动（金黄 #FFD700/#FFF8DC/#FFA500）三套方案，全篇样式统一、配色一致。
- **图片规则**：每张照片配一句说明（上下图文样式）；图片之间至少隔一段文字，避免连续堆叠。
- **样式选择**：底色标题/编号标题/卡通图片标题三类；同系列样式搭配使用。
- **关键认知**："80% 家长通过一篇推文判断幼儿园的专业度"——排版是信任资产，不是装饰。
