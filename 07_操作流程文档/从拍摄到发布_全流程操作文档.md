# 从拍摄到发布 · 幼儿园活动宣传全流程操作文档

> 适用场景：幼儿园主题活动（运动会、节日活动、安全教育等）的公众号宣传
> 本案例：《秋季安全教育主题活动》
> 工具清单：手机/相机、剪映（手机版或专业版）、醒图/Snapseed（修图）、微信公众平台、Canva 或稿定设计（封面/海报）

---

## 一、总流程图（8 步）

```
前期策划 → 拍摄清单 → 现场拍摄 → 选片修图 → 视频剪辑 → 图文撰写 → 排版发布 → 数据复盘
 (1天)     (0.5天)    (活动当天)  (当天晚上)   (1–2小时)    (1小时)     (30分钟)    (发布后3天)
```

## 二、分步操作

### 第 1 步：前期策划（活动前 1 周）
1. 和带班老师确认活动流程表、亮点环节（本案例：三大体验区+教师示范+打卡墙）。
2. 确定宣传主题词（本案例："知危险 · 会避险"），统一视觉色调（秋日暖橙+安全红绿）。
3. **合规确认（必做）**：核对幼儿肖像授权名单，未授权的儿童一律不拍正脸、不拍特写；可用背影、手部、剪影、道具和环境镜头替代。本作品集即采用"无真实儿童"的模拟方案。

### 第 2 步：拍摄清单（0.5 天）
按"空镜 → 物料 → 场景 → 人物（合规范围内）"四类列清单，每类至少 3 张：

| 类别 | 本案例清单 |
|---|---|
| 环境空镜 | 秋日校园、拱门横幅、场地全景 |
| 物料特写 | 海报、指示牌、签到板、物资平铺 |
| 场景中景 | 三大体验区、知识展板 |
| 人物（合规） | 成人教师示范剪影、道具互动（避开儿童正脸） |

### 第 3 步：现场拍摄（活动当天）
- 光线：户外顺光/侧光为主，避开正午顶光；室内靠窗位置，必要时补一盏常亮灯。
- 构图：环境用横平竖直的对称/引导线构图；特写用三分法；平铺物资用 90° 俯拍。
- 数量：每个环节连拍 3–5 张，全程 60–100 张，后期只留 10–15 张。
- 视频：每个环节拍 5–10 秒固定镜头 + 2–3 个慢推近景，横屏 16:9。

### 第 4 步：选片与修图（当晚，醒图/Snapseed 均可）
1. 初筛：糊片、闭眼、杂乱背景直接删除；按环节分组。
2. 每张统一按四步调：
   - **亮度** +5~+10（暗部提亮）
   - **对比度** +10~+15（拉开层次）
   - **饱和度/色温** +15~+25 / 偏暖（强化秋日氛围）
   - **锐化** +10（突出主体）
3. 导出两张版本："调整前"与"调整后"留档对比（见本作品集 02_修图对比）。

### 第 5 步：视频剪辑（剪映，目标 30–60 秒）
1. **导入**：新建 16:9 项目，按"片头字卡 → 活动流程顺序 → 片尾"排列素材。
2. **每段时长**：单镜头 2.5–3.5 秒，全程控制在 45 秒内。
3. **动效**：相邻镜头交替使用"推近/拉远"（剪映：动画 → 入场动画 → 缩放），避免连续同向。
4. **转场**：统一用"叠化 0.5–0.6s"，不要使用花哨转场。
5. **字幕**：每段加一句说明字幕（剪映：文字 → 新建文本，字体选"思源黑体"，字号 5–6，白字+深色底条）。
6. **音乐**：从剪映音乐库选"轻快/温馨"标签曲目，音量 30%，片尾 2 秒淡出。
7. **导出**：1080P / 30fps，先发家庭群试看，确认无误再上传公众号素材库。

### 第 6 步：图文撰写（约 600–800 字）
- **标题公式（对 10 篇真实园所推文取样归纳，八成适用）**：
  1. 谐音双关对仗式（最主流）：`防患未"燃"，安全"童"行——XX幼儿园XX活动精彩回顾`（"童"替"同"、"燃"替"然"）
  2. 五字对仗口号式：`演练筑防线，平安护童年——记XX幼儿园XX活动`
  3. 新媒体活泼式（涨阅读量）：`萌娃"火"速撤离！这场幼儿园消防演练，安全感拉满~`
- **正文结构**：目的+意义式导语（"为进一步……"）→ 3–5 个四字/八字短句小标题分段（每段配图）→ 意义升华 → 承诺式结尾（"将持续……保驾护航！"），可选加家园共育小贴士。
- 每段不超过 5 行，多分段、每图配一句图注；文末放下一期活动预告。

### 第 7 步：排版与发布（公众平台后台）
1. 封面：头条 900×383px，次条 200×200px（本作品集 04_封面图 已按此规格制作）。
2. 排版规范（行业通行值）：正文 15–16px、行间距 1.75–2.0、段间距 15–20px；小标题 18–20px 加粗；全篇配色统一（活动类建议暖色：主 #FFA500 / 辅 #FFF8DC / 强调 #C24233，正文 #3F3F3F）。
3. 图片规则：每图配一句图注，图片之间至少隔一段文字，不连续堆叠；导出宽 1080px 再上传。
4. 摘要 ≤120 字，提炼活动最亮点；原文链接可挂报名页。
5. 发布时间：工作日 19:00–20:30 家长浏览高峰；发布后 10 分钟内转发教师群、家长群。

### 第 8 步：数据复盘（发布后 3 天）
记录：阅读量、在看/点赞、转发数、涨粉数；对比往期找出高转化标题与封面规律，写入下期策划。

## 三、常见问题

| 问题 | 处理办法 |
|---|---|
| 家长临时不同意孩子出镜 | 现场只拍背影/俯拍头顶，或后期用贴纸遮挡 |
| 阴天光线不足 | 修图只提亮度别拉曝光，加色温找回暖感 |
| 视频超 60 秒 | 优先删过渡性镜头，保留"动作完整"的镜头 |
| 图片上传后发糊 | 用 JPG 质量 80 以上，宽 1080px，勿截图后再传 |

## 四、合规红线（务必遵守）

1. 未获监护人书面授权，**不得**发布任何可识别儿童身份的正脸照、姓名、班级信息。
2. 视频中出现儿童画面须逐帧检查，必要时打码或裁切。
3. 网络音乐/字体须确认商用授权（剪映曲库内标"可商用"的曲目），避免侵权。
4. 本作品集全部素材为程序生成的模拟插画，未使用任何真实儿童影像与个人信息，可作为无授权情况下的示范方案。
