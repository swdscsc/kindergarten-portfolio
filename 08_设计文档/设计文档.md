# 设计文档 — 幼儿园活动摄影、视频剪辑与公众号宣传作品集

> 版本：1.0 ｜ 2026-10-31 ｜ 本文档说明作品集的信息架构、视觉规范、内容策略、技术实现路线与技术难点。

## 1. 目标与受众

- **目标**：向招聘方证明候选人具备"摄影摄像 → 后期制作 → 新媒体运营 → 流程管理"的完整宣传能力，且懂幼儿行业的隐私合规。
- **受众**：幼儿园园长/人事、教育集团行政与信息化负责人。
- **约束**：无实拍条件、无真实儿童肖像授权 → 采用"程序生成模拟素材"方案。

## 2. 信息架构（交付物设计）

按"生产流水线"组织而非按"文件类型"堆放，每个文件夹对应工作流的一个环节：

```
策划(07) → 拍摄(01) → 修图(02) → 剪辑(03) → 设计(04) → 撰写(05) → 管理(06) → 质量验收(09) → 求职转化(10)
```

设计取舍：
- 用 `00_总说明` + `README` 双入口：README 面向 GitHub 招聘方，00 面向面试现场快速导览。
- 分镜脚本（08_视频剪辑脚本素材 → 后并入 03）随成片放置，证明"先写脚本再剪辑"的职业习惯。
- 推文拆解笔记独立成文，把"内容方法论"显性化。

## 4. 内容策略

1. **标题**：主标题采用真实园所推文最高频的「谐音双关对仗 + 园所名 + 活动名」：《防患未"燃"，安全"童"行——阳光幼儿园秋季安全教育主题活动精彩回顾》；备选覆盖五字对仗式与萌娃活泼式。
2. **正文**：目的式导语 → 四字/八字小标题分段（每段一图）→ 意义升华 → 保驾护航承诺式结尾 + 家园共育贴士；正文控制在 600–800 字（实测 730 字）。
3. **发布建议**：工作日 19:00–20:30 家长浏览高峰；摘要 ≤120 字；发布后 10 分钟内转发家长群。

## 5. 技术实现路线

| 环节 | 方案 |
|---|---|
| 照片 | Python + Pillow 程序绘制扁平插画（渐变、圆角、叶片多边形、成人剪影函数库），叠加噪点+暗角模拟摄影质感 |
| 修图对比 | 同源图像先做"直出"劣化（亮度0.88/饱和0.78/对比0.92）再做增强（亮度1.08/对比1.12/饱和1.22/锐化），PIL 拼接对比版并标注参数 |
| 视频 | 两遍法流水线：PIL 预合成字幕帧 → ffmpeg zoompan 逐段渲染（推近 1+0.0012*on / 拉远 max(1.10-0.0012*on,1)）→ 链式 xfade 0.6s 叠化 → 程序合成 WAV 和弦垫（C-G-Am-F + 铃声，淡入淡出）→ x264/AAC 封装 |
| 音频 | 纯 Python 生成 44.1kHz 单声道 PCM：正弦和弦垫 + 指数衰减铃声，零素材库依赖 |
| 文档 | Markdown 为单一事实源，python-docx 脚本转换 Word，保证两版本一致 |
| 质量验收 | run_tests.py 17 项断言（文件完整性/图片规格/视频元数据/文档可读性/字数/README 完整性），真实执行并可接 CI |

## 6. 技术难点与解决过程（面试讲述版）

### 难点 1：ffmpeg 链式转场"滤镜图未连接"报错
- **现象**：`Filter format:default has an unconnected output`，滤镜图逻辑肉眼检查完全正确。
- **定位**：控制变量二分——2 输入+xfade 通过；3 输入+链式 xfade 失败；3 输入+concat 通过；去掉 zoompan 后通过。锁定触发条件："单帧图片输入 + zoompan 扩帧 + 链式 xfade"（ffmpeg 7.1 essentials 构建）。
- **解决**：改两遍法——每段先渲染为独立 mp4，再对真实视频流做 xfade。一次通过，且中间段可单独复用（素材库化）。
- **收获**：报错信息不指向根因时，用最小用例二分定位比读源码更快。

### 难点 2：无素材条件下的"摄影感"
- 纯矢量插画缺少照片质感 → 叠加高斯分布噪点 + 椭圆暗角遮罩（模糊 180px）模拟镜头渐晕，观感立刻接近直出照片，也为"修图对比"环节提供了真实的调整空间。

### 难点 3：内容可信度
- 招聘方一眼能识别"作业腔"文案 → 先取样 10 篇真实园所推文（搜狗微信 3766 条结果首页）归纳标题/结构/套话规律，再按规律重写，并保留拆解笔记。让每句话都有出处。
