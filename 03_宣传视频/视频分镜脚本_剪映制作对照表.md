## 剪映逐步操作
1. 新建项目 → 比例 16:9 → 按上表顺序导入图片素材。
2. 选中每张图片 → 时长改为 3.2s →「动画」→ 入场选「缓缓放大」（推近镜头）或「缓缓缩小」（拉远镜头），时长 3.2s。
3. 片头片尾：「文字」→ 输入字卡文案 → 字体"新青年体/思源黑体 加粗"，加红色底色文本条。
4. 每段加字幕：「文字 → 新建文本」，白字 + 黑色 40% 透明底条，底部居中。
5. 转场：两段之间「转场 → 叠化 → 0.6s」。
6. 音乐：「音频 → 音乐 → 搜"温馨 轻快"」→ 音量调至 30% → 片尾手动截断并加"淡出 2s"。
7. 导出：1080P / 30fps。
