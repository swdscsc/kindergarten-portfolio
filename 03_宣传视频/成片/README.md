# MP4 成片目录

将本轮独立交付的三条 MP4 放入本目录后，可运行：

```bash
python 09_验收测试/run_tests.py
```

本轮成片文件名：
- `01_编辑部纪实风.mp4`
- `02_路径信息图风.mp4`
- `03_清单排版风.mp4`

三条均为 720×1280、24fps、12 秒、H.264，静音字幕版。视频由原创中文编辑式动态图形、信息路径和清单动效生成。

当前 GitHub 仓库保存可复现的 Python 生成脚本与分镜说明；高画质 MP4 作为本次对话的独立文件交付。下载后放入本目录，再提交即可与仓库项目一起保存。

视频为模拟动态图形，不代表真实园所活动。正式发布前应按园方流程核实信息、完成素材授权和审核。
