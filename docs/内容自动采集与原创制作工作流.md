# 幼儿园内容自动采集与原创制作工作流

> 作品集演示方案。目标是建立“公开信息采集—案例拆解—原创策划—素材制作—人工审核—发布复盘”的内容生产流程。未经授权不抓取登录后内容、不下载或再发布他人视频/图片，不自动发布。

## 1. 内容生产目标

- 原创短视频：6种不同叙事类型，分别体现纪实、活动、科普、亲子、课程和信息化管理能力。
- 原创公众号：6篇不同主题文章，包含标题、导语、正文、配图规划、版式建议和审核清单。
- 自动采集：定时汇总政策资讯、节日节点、公开园所案例、开放许可图片和可复用的公开教育资源。
- 人工把关：选题、事实、版权、儿童隐私、最终成片和发布均需人工审核。

## 2. 建议采集来源

| 来源 | 采集内容 | 使用边界 |
|---|---|---|
| 教育部官网（moe.gov.cn） | 学前教育政策、宣传月主题、科学保教信息 | 提取事实与政策要点，保留原文链接；不整段照搬 |
| 国家/地方教育部门官网 | 地方活动、典型经验、教育通知 | 作为选题与事实依据，注明来源和日期 |
| 全国学前教育宣传月专题 | 典型案例、年度主题、科学育儿方向 | 学习选题角度和内容结构，不复制稿件 |
| Wikimedia Commons | 园舍、环境、公共教育场景图片 | 逐张核对许可、作者、署名和肖像权限制 |
| 自制素材库 | 原创插画、图标、动画、模拟界面、实拍素材 | 记录作者、生成方式、日期和授权情况 |
| 公开园所公众号/官网 | 选题、叙事、栏目、版式案例 | 只分析公开页面；不搬运文章、图片、视频 |

## 3. 自动采集流程

建议用 n8n 每天定时运行一次：

1. Schedule Trigger：每天上午 8:30 触发。
2. HTTP Request / RSS Read：读取官方站点公开 RSS、栏目页或公开接口；没有稳定 RSS 的站点只抓公开页面标题、日期、摘要和原文链接。
3. HTML Extract：抽取标题、发布时间、摘要、来源链接。
4. 去重：按规范化 URL 和标题指纹去重。
5. 分类：政策、安全、家园共育、特色课程、节日活动、信息化管理。
6. 选题评分：相关性、时效性、可执行性、原创空间、版权风险各 1—5 分。
7. 汇总：生成每日素材简报，写入 Markdown/表格或 Notion/本地文件。
8. 人工确认：只把通过审核的主题送入脚本创作环节。

注意：站点没有公开 RSS/API 时，不应假定存在接口；遵守网站 robots、使用条款和访问频率限制，不绕过登录、验证码或访问控制。

## 4. 案例分析卡

每条参考案例只记录可供学习的抽象方法：

- 原文标题、来源机构、发布日期、原文 URL
- 内容主题与目标受众
- 开头如何吸引注意
- 叙事结构（问题—过程—结果、时间线、人物视角等）
- 画面/版式节奏与信息层级
- 值得借鉴的表达方法
- 必须避开的原文句子、独特视觉资产和受版权保护素材
- 本项目的新选题、新观点、新脚本

## 5. 原创短视频计划（6类）

| 编号 | 题目 | 类型与风格 | 建议时长 | 原创呈现 |
|---|---|---|---:|---|
| V01 | 幼儿园的一天，藏着多少小美好 | 温情叙事/微纪录片 | 60—90秒 | 原创旁白、生活细节、节奏剪辑；无真实素材时用动画模拟 |
| V02 | 一场消防安全活动是怎样完成的 | 活动纪实/流程快剪 | 45—60秒 | 原创分镜、流程图形、模拟演练画面 |
| V03 | 孩子在幼儿园，怎样学会保护自己 | 科普/情景动画 | 45—60秒 | 原创情景、知识卡片、字幕重点 |
| V04 | 放学后，10分钟高质量陪伴 | 亲子建议/轻访谈 | 60—90秒 | 原创建议、家庭情境演示、清单动画 |
| V05 | 一颗种子，怎样变成一堂自然课 | 课程故事/延时叙事 | 60—90秒 | 生长过程、观察卡、原创图解 |
| V06 | 信息管理员的一天 | 岗位展示/屏幕录制 | 60—90秒 | 模拟资产登记、报修闭环、数据看板和备份流程 |

每条视频交付：选题卡、脚本、分镜、素材清单、旁白、字幕 SRT、封面、剪辑工程/制作说明、导出 MP4、版权与隐私检查表。

## 7. 统一原创与版权规范

- “参考”只用于学习选题、叙事和信息组织；不复制他人文章、脚本、分镜、配乐、视频片段或设计稿。
- 优先使用原创图形/动画、本人实拍、明确开放许可素材或取得书面授权的素材。
- 开放许可素材必须逐项记录作者、来源 URL、许可类型、署名文本及访问日期；CC BY-SA 等许可需遵守相应再利用与相同方式共享要求。
- 儿童影像、姓名、声音、班级、健康与家庭信息属于高敏感场景。没有监护人有效授权和园方批准，不使用可识别儿童素材；优先拍摄园舍、教具、手部特写、成人示范、背影或动画。
- 不将模拟活动、AI生成画面或公开案例描述为本人真实工作经历。
- 自动化只生成待审核内容，不自动登录公众号后台、不自动发布。

## 8. 验收标准

- [ ] 每个选题均有来源记录与原创角度说明
- [ ] 6条视频风格明显不同，脚本、旁白、字幕、封面齐全
- [ ] 6篇公众号文章均为原创完整稿，配图和排版方案齐全
- [ ] 所有素材有来源、许可或自制记录
- [ ] 儿童隐私与肖像权检查通过
- [ ] 事实与政策信息有可追溯来源
- [ ] 视频能正常播放，字幕无错字，音画同步
- [ ] 公众号稿件可复制到编辑器，手机预览无明显错位
- [ ] 发布动作保留人工确认
