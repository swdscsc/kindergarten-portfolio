# 中国幼儿园宣传与公众号案例研究

> 用途：幼儿园集团信息管理员求职作品集的行业研究依据。本文是公开资料的分析笔记，不代表本人曾在这些园所任职或参与报道制作。

## 1. 上海青浦区：消防车进幼儿园

- 原文：[“幼儿园里来了消防车”，孩子们变身“小小消防员”](https://www.shqp.gov.cn/shqp/qpyw/20231123/1149140.html)
- 发布单位：上海市青浦区人民政府，来源注明“绿色青浦”微信公众号。
- 观察到的报道结构：
  1. 交代消防宣传月主题与活动目的；
  2. 消防车、救援装备进园；
  3. 疏散演练过程；
  4. 装备讲解与操作体验；
  5. 幼儿体验和活动意义总结。
- 摄影拆解：装备与场地全景用于交代环境；疏散过程照片呈现活动真实性；装备操作和体验细节支撑正文；合影作为收束，不应取代过程照片。
- 可迁移做法：活动开始前先列出“场景全景、过程记录、互动细节、成果收束”镜头清单。
- 不应照搬：原报道照片、人物肖像、原文段落及引语；除非取得权利人授权，不得下载后作为自己的摄影作品。

## 2. 杭州西湖区翠苑第四幼儿园：公众号编辑培训

- 原文：[提升公众号编辑技能 赋能教师专业成长](https://www.hzxhjy.cn/cydsyey/jyzx/jyzx_2009/202605/t20260517_757971.shtml)
- 发布单位：杭州市西湖区翠苑第四幼儿园。
- 报道提及的编辑要点：模板选择、标题制作、排版技巧、图片处理；模板建议童趣、简约、避免商业化；可结合季节和主题搭配莫兰迪色系；强调横构图、适当留白、图片数量与模板匹配，以及多手机预览。
- 可迁移做法：建立园所中文视觉规范，统一标题层级、字体、色彩、图片比例和段落间距；发布前进行多设备预览。
- 注意：色彩和模板只是视觉工具，不能替代内容准确、图片授权和儿童隐私审查。

## 3. 四川江安：公众号编辑与摄影专题培训

- 原文：[淯江幼儿园开展公众号编辑技巧暨摄影技巧专题培训](https://yibin.scjyxw.com/xiaoxue/news/20230321/1000010000320088.html)
- 发布来源：四川教育在线，来源标注淯江幼儿园。
- 报道涉及：会议拍摄、人像拍摄角度、摄影构图、手机拍摄注意事项；随后以秀米演示图文编排、材料选择和发布流程。
- 可迁移做法：拍摄与编辑不应分离。策划阶段就要考虑最终图文结构和图片需求。

## 4. 上海奉贤：幼儿园专属信息团队

- 原文：[文字有力量 宣传有温度——打造幼儿园专属信息团队](https://www.fengxian.gov.cn/jyj/xwzx/xczmb/20240729/74186.html)
- 发布来源：上海市奉贤区教育局。
- 报道提出的工作环节：图片拍摄、处理、存档；宣传报道撰写、审核、修改；信息团队分工；准确性与时效性。
- 可迁移做法：将宣传工作做成可追溯流程，明确采集、撰稿、审核、发布和归档责任。

## 5. 成都五幼浣花园：公众号制作培训

- 原文：[玩转“公众号” 成都五幼浣花园开展公众号制作培训](https://www.scjyxw.com/xiaoxue/news/20240415/1000010000373626.html)
- 发布来源：四川教育在线，来源标注成都市第五幼儿园浣花园。
- 报道强调：标题简洁明了、内容不宜过长、凸显特色、详略得当，图片质量影响整体观感。
- 可迁移做法：建立标题、正文、图片质量三项发布检查表。

## 6. 中国网：亲子消防运动会

- 原文：[消防润童心·安全伴“童”行 成都树基森林幼儿园举办亲子消防运动会](https://guoqing.china.com.cn/2024-11/08/content_117534336.htm)
- 发布来源：中国网。
- 可观察内容：亲子协作、游戏任务、活动现场和总结，报道以具体活动环节呈现主题价值。
- 可迁移做法：避免空泛口号，优先记录参与者做了什么、活动如何开展、主题如何落地。

## 7. 从案例归纳的作品集验收标准

| 维度 | 合格标准 |
|---|---|
| 真实性 | 园所、时间、人数、活动过程和引语均有真实依据；模拟案例醒目标注 |
| 摄影 | 全景、中景、细节和过程镜头齐全；曝光、对焦、构图可用 |
| 中文文案 | 标题简洁，导语交代要素，正文准确、精炼、无虚构 |
| 中文排版 | 标题层级清晰、字体统一、配色克制、段落适合手机阅读 |
| 图片管理 | 原片与成片分开，文件命名规范，记录作者、来源和许可范围 |
| 发布审核 | 事实、错别字、肖像授权、隐私、版权、链接均有检查记录 |
| 归档复盘 | 保留终稿、源文件、授权记录、发布链接和复盘数据 |

## 8. 图片素材使用边界

- 政府网站、园所官网、教育媒体公开报道中的图片，仍可能受到著作权、肖像权和隐私权保护。
- 公开可访问不等于可下载、修改、转载或用于求职作品集。
- 作品集可链接原始报道供招聘方核验，不将第三方图片包装成个人拍摄。
- 如需使用第三方图片，应先取得明确书面授权，并记录作者、原始链接、授权范围、期限、署名要求。
- 若无法获得授权，使用本人拍摄的园所环境、布置、教具、成人示范等素材，或使用明确允许相应用途的图库素材并标注来源。
- 涉及可识别儿童的照片，发布前按园方制度取得必要监护人同意；不展示儿童姓名、班级、定位和其他不必要个人信息。
