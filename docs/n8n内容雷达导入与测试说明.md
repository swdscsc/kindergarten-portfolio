# n8n「幼儿园内容雷达」导入与测试说明

对应工作流：`automation/n8n/幼儿园内容雷达-每日选题采集.json`

## 1. 导入

1. 打开你自己的 n8n。
2. 进入 Workflows，选择 Import from File。
3. 选择仓库中的 `幼儿园内容雷达-每日选题采集.json`。
4. 保存工作流，先保持 Inactive（关闭状态）。
5. 打开工作流，检查三个 RSS Feed Read 节点是否存在，确认节点没有红色报错。

## 2. 手动测试

1. 点击 Execute Workflow 手动执行，不要先激活定时运行。
2. 检查三个 RSS 节点是否分别返回资讯条目。
3. 检查「合并资讯」「合并全部资讯」节点是否合并出三路结果。
4. 检查「去重分类与选题初筛」节点输出字段：title、link、pubDate、source、category、priorityScore、summary、reviewStatus。
5. 点击每条 link 打开原始页面，核实标题、日期、内容和发布机构。RSS 摘要可能不完整，不能仅凭摘要写政策结论。

## 3. 定时运行

测试通过后再 Activate。工作流按 n8n 实例时区每天 08:30 运行。请先在 n8n 设置中确认实例时区为 Asia/Shanghai；否则执行时间可能与预期不同。

## 4. 如何把结果交给内容创作

每天先人工挑选 1—3 条有价值的选题，再为每条建立案例分析卡：
- 来源机构、原文标题、发布日期、原文 URL
- 事实摘要（只记录原文支持的信息）
- 受众与实际问题
- 参考案例采用的叙事方法
- 我们的新角度、新观点和原创表达
- 需要补充核实的事实
- 图片/视频素材的许可和授权状态

之后才进入视频脚本或公众号正文生成，不允许把参考文章直接改几个词当作原创。

## 5. 常见问题

- **没有结果：** RSS 搜索结果可能暂时为空或地区策略变化；检查节点输出、网络访问和 RSS URL。不要把“无结果”误判为“没有相关资讯”。
- **某个来源报错：** 单独执行该 RSS 节点，检查网络、响应格式和来源可用性。
- **重复条目：** 当前按 link 去重；如果同一新闻有多个转载 URL，需要人工合并判断。
- **摘要乱码/HTML：** 以原文页面为准；当前代码只清理基础 HTML 标签，不保证覆盖所有格式。
- **时间不对：** 检查 n8n 实例时区和 RSS 返回的 pubDate。

## 6. 安全与合规

- 只采集公开 RSS 内容与公开页面元数据，遵守站点服务条款、robots 规则和合理访问频率。
- 不绕过登录、验证码、付费墙或访问控制。
- 不批量下载其他园所的图片、视频或公众号全文。
- 参考案例用于选题研究和结构分析，原创作品需重新构思并使用自有/授权素材。
- 工作流只生成待审核数据，不连接公众号发布接口，不自动对外发布。
