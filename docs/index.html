05 / 制作流程与交付

把一次活动宣传变成可复用的工作流程

制作流程

  1. 明确活动目标、受众与发布渠道
  2. 制定拍摄清单、镜头脚本与授权检查
  3. 完成照片筛选、修图和素材命名
  4. 按脚本剪辑短视频并校对字幕
  5. 撰写推文、设计封面并进行移动端预览
  6. 复核隐私、肖像授权、事实与错别字
  7. 发布后归档源文件并复盘数据

项目文件

  • 作品集总说明
