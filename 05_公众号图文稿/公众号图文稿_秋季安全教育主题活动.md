# 公众号图文稿示例（模拟案例｜发布前必须核实事实）

> 本稿用于展示选题、结构、配图节奏和编辑能力，不是已发生的园所新闻。
> “阳光幼儿园”为虚构示例名称；活动日期、活动流程、现场表现、人物引语均为占位示例。不得原样作为真实新闻发布。
> 正式使用时，请将所有【待核实】字段替换为园方确认的信息；没有采访记录就删除引语，不得编造家长/教师评价。

## 发布前事实核查清单

- [ ] 园所名称、活动名称、日期、地点均由园方确认
- [ ] 每个活动环节均有现场记录或负责人确认
- [ ] 人物引语有真实采访记录；无记录则删除
- [ ] 不虚构参与人数、活动效果、获奖情况或家长评价
- [ ] 儿童肖像、姓名、班级、健康/家庭信息已完成授权与隐私审核
- [ ] 图片来源、摄影者、授权范围、署名要求已登记
- [ ] 标题、正文、图片说明、封面与发布账号完成复核

## 排版与交付建议（上线前按公众号后台预览）

| 项目 | 本项目示例设置 |
|---|---|
| 头条封面 | 900×383px，使用仓库模拟封面；真实发布须换成已授权素材 |
| 次条封面 | 200×200px |
| 摘要 | 以真实活动内容提炼，不添加未证实效果 |
| 正文 | 移动端优先，短段落、小标题清晰，图片与文字互相印证 |
| 图片 | 原则上逐张检查清晰度、构图、隐私、版权及图注 |
| 发布时间 | 由园方发布计划决定，不将所谓“流量时段”当作固定规则 |
| 发布审核 | 编辑初审 → 业务负责人核实 → 园方授权/隐私审核 → 账号管理员终审 |

## 参考依据

本示例的合规流程参考《中华人民共和国学前教育法》第二十一条关于学前儿童合法权益、个人信息处理及新闻报道客观审慎适度的要求；第三方摄影作品使用须核对版权许可。具体执行以园方制度及现行法律法规为准。
