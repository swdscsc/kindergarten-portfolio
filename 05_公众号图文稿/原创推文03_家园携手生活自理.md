# 孩子想自己来，成人可以先等等

> **模拟原创稿｜家园共育**
>
> 本文为生活自理主题内容示例，不代表某所幼儿园已开展相关活动。园所正式发布前，应结合实际年龄段和保育要求审核。

**摘要：** 穿外套、收玩具、整理个人物品，孩子需要时间练习。成人可以把任务拆小一点，先观察，再决定什么时候帮忙。

## 慢一点，不等于做得不好

孩子自己穿外套，可能要试几次才找到袖口；收玩具时，也可能先拿起一件又放下另一件。成人看起来很简单的事情，对孩子来说却包含了辨认、计划和动作协调。

如果时间允许，可以先留一点等待时间。孩子正在尝试时，不必马上接手；如果确实需要帮助，就示范一个关键动作，再让孩子继续完成。

## 把一件事拆成几步

以整理玩具为例，可以先从三个动作开始：

1. 把同类玩具放在一起。
2. 找到对应的收纳盒。
3. 放好后看一眼桌面还有没有遗漏。

收纳位置固定、盒子有简单图示，能让孩子更容易找到下一步。任务不要一次增加太多，先让孩子熟悉，再慢慢调整。

穿衣、餐后整理和收拾个人物品也可以采用类似方法。成人应根据孩子的年龄、动作能力和当天状态提供帮助，不把速度当成唯一标准。

## 鼓励要说到具体地方

“真棒”当然可以说，但如果能指出孩子刚才做了什么，反馈会更清楚。

例如：“你记得把积木放回原来的盒子了。”“刚才拉拉链时，你先找到了拉头。”这样的表达让孩子知道自己的努力在哪里。

如果孩子今天不愿意尝试，也不必用“别人都会了”来比较。可以先把任务缩小，或等情绪平稳后再试。

## 家里和园里，可以选一件事一起练

| 日常事情 | 可以提供的帮助 |
|---|---|
| 整理玩具 | 固定收纳位置，减少一次要整理的数量 |
| 穿脱外套 | 先示范一个动作，给孩子留出时间 |
| 餐后整理 | 用简短提醒帮助孩子找到自己的物品 |
| 整理书包 | 由成人陪同核对，不把全部任务交给孩子独自承担 |

家园沟通时，可以先选一件双方都方便配合的小事。做法尽量一致，但不必要求家庭和园所完全相同；如果孩子在某个环节需要更多帮助，成人再一起调整。

## 独立不是“什么都自己做”

生活自理的练习不是比赛，也不是让孩子承担超出年龄的责任。知道什么时候可以自己试，什么时候应该寻求帮助，同样重要。

成人愿意多等一会儿，孩子就多了一次练习的机会。今天只完成了一小步，也值得被看见。
