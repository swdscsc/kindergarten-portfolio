# 园务信息台｜Campus Information Desk V2.0

面向幼儿园集团信息管理员岗位的本地可运行演示系统，使用 Flask + SQLite。

## V2.0 新增能力
- **列表搜索**：设备台账按编号、名称、类别、位置搜索；工单按编号、设备、故障描述、部门、状态搜索；素材按活动、类型、授权状态、归档路径搜索。
- **CSV 导出**：设备、巡检、工单、素材、操作记录均可导出，使用 UTF-8 BOM，方便 Excel 打开。
- **操作记录**：记录新增设备、巡检、创建/更新工单、素材归档等关键动作。此记录仅用于演示，不是不可篡改的生产审计。
- **数据库备份**：下载 SQLite 数据库副本，需 Python 3.11+。
- **健康检查**：/health。

## Windows 启动
建议 Python 3.11 或更新版本。

```powershell
cd 04_园务信息台
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
浏览器打开 http://127.0.0.1:5000。停止运行按 Ctrl+C。

## 冒烟测试
另开 PowerShell，进入本目录并激活虚拟环境：
```powershell
python smoke_test.py
```
测试使用临时 SQLite 数据库，不会修改正式演示数据。

## V2.0 演示流程
1. 总览查看虚构的设备和工单。
2. 新增设备并用搜索框检索。
3. 登记巡检并查看设备最近巡检日期。
4. 新建工单、更新状态，查看操作记录。
5. 登记模拟宣传素材并检索。
6. 在“数据工具”导出 CSV、下载数据库备份。

## 数据位置
首次启动生成 data/campus_demo.db。数据库不提交 GitHub。页面“数据工具”可下载 CSV 或 SQLite 备份；备份文件可能包含全部业务记录，请勿上传公开仓库。

## 真实性与安全边界
- 所有初始记录均为虚构演示数据，不代表真实园所设备、活动或运维记录。
- 不要录入真实儿童姓名、照片、健康信息、家庭联系方式、接送信息或其他敏感数据。
- 当前为本机单用户演示：没有登录认证、角色权限、CSRF 防护、生产级审计、加密备份或生产部署配置。
- CSV 导出和数据库备份没有身份鉴权；任何能访问本机页面的人都能使用。仅在可信本机环境运行。
- Flask 开发服务器绑定 127.0.0.1，不要暴露公网或用于真实园所业务。
- 投入真实使用前，必须补齐身份认证、角色权限、CSRF 防护、输入校验、日志审计、备份加密、数据保留与删除机制，并经园方授权和安全评估。
