# 园务信息台｜Campus Information Desk

一个面向幼儿园集团信息管理员岗位的本地可运行演示系统，使用 Flask + SQLite。

## 功能

- 工作总览：设备数量、异常设备、未完成工单、素材归档统计。
- 设备台账：新增设备，记录编号、类别、位置、责任人、状态。
- 巡检记录：新增巡检结果，关联设备并更新最近巡检日期。
- 故障工单：提交报修，更新待受理/处理中/待复核/已完成状态，记录处理人和结果。
- 素材归档：登记活动日期、素材类型、数量、授权状态、归档路径和审核人。
- SQLite 本地数据库：首次启动自动建表并写入虚构演示数据。

## Windows 启动

建议 Python 3.10 或更新版本。

```powershell
cd 04_园务信息台
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

浏览器打开： http://127.0.0.1:5000

停止运行：在终端按 Ctrl + C。

## 数据位置

首次启动自动生成 `data/campus_demo.db`。删除该文件后再次运行，会重新生成演示数据。数据库不提交到 GitHub。

## 演示流程

1. 打开总览，查看示例设备、异常设备和未完成工单。
2. 在设备台账中登记一台新的模拟设备。
3. 在巡检记录中选择该设备，登记一次“正常”或“异常”巡检。
4. 在故障工单中新建报修，再更新状态为“处理中”或“已完成”。
5. 在素材归档登记一条模拟活动记录，检查授权状态和归档路径。

## 真实性与安全边界

- 页面所有初始记录均为虚构演示数据，不代表真实园所的设备、活动或运维记录。
- 不要录入真实儿童姓名、照片、健康信息、家庭联系方式、接送信息或其他敏感数据。
- 当前为本机单用户演示：没有登录认证、角色权限、CSRF 防护、审计日志、备份恢复策略和生产部署配置。
- Flask 开发服务器只绑定本机回环地址 `127.0.0.1`。不要将其直接暴露到公网或用于真实园所业务。
- 若要投入真实使用，必须先补充身份认证、角色权限、CSRF 防护、输入校验、日志审计、加密备份、数据保留与删除机制，并经园方授权和安全评估。
