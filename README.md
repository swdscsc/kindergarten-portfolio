# 幼儿园活动宣传作品集

> 模拟案例：《秋季安全教育主题活动》｜求职方向：幼儿园集团信息管理员 / 信息技术支持 / 宣传与办公自动化

## 项目说明

本仓库展示一套幼儿园活动宣传工作流：活动策划、拍摄规划、图片处理、短视频剪辑、公众号图文、素材归档和质量检查。

**真实性边界：** 当前仓库的活动场景图为原创程序绘制的模拟视觉素材，不是真实园所实拍；“阳光幼儿园”为模拟名称，不代表真实单位或已落地项目。仓库另提供真实园所/教育部门公开报道的参考链接，用于研究图片叙事和公众号内容结构。第三方报道中的照片版权归原发布方及摄影作者所有，本仓库不下载、不转载、不声称为本人拍摄。

## 运行与验收

本项目是媒体作品与文档，无需编译。视频可用浏览器、VLC 或 Windows 播放器打开；Word 文件可用 Word/WPS 查看。

```bash
python 09_验收测试/run_tests.py
python 09_验收测试/run_tests.py --json
```

测试脚本检查素材完整性、图片尺寸、视频元数据、文档和内容约束。以本地实际运行结果为准。

## 如何升级为真实摄影作品

正式用于求职展示时，优先使用本人拍摄且取得必要授权的园所环境、活动布置、教具、空镜和成人演示照片。若使用第三方园所照片，须先取得权利人明确许可，并在素材清单记录作者、来源、许可范围、署名方式和使用期限。公开可访问不等于允许下载、修改或再发布。

未经家长/监护人和园方授权，不公开儿童可识别面部、姓名、班级、定位信息或其他个人信息。无法取得授权时，使用空镜、背影、手部特写、道具与模拟场景。
