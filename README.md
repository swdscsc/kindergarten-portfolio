## 项目定位

本仓库围绕幼儿园集团信息管理员的工作场景，展示园所宣传内容策划、中文公众号编辑、摄影与短视频流程、素材归档、信息化办公支持等能力。

当前网页采用**原创模拟项目 + 中国行业案例研究**两条线：原创视觉、文案和视频用于展示制作能力；公开报道用于拆解编辑流程和品牌视觉方法。新增的信息管理模板用于演示日常工作记录、问题闭环和资料交接方法。三类内容明确区分。

## 重要真实性说明

- 行业案例来自公开报道，仅用于学习分析；不代表本人参与过这些园所活动。
- 第三方报道中的图片、文字版权归原权利人。公开可访问不等于允许下载、修改、转载或用于个人作品集。
- 本轮新增的原创模拟视觉、宣传物料和程序化视频是作品集核心展示内容，均明确标注为模拟演示，不得声称为真实园所实拍。
- 信息管理台账为岗位流程演示模板，不代表本人已在真实园所执行相关巡检或运维工作。
- 正式摄影作品需要本人拍摄并取得必要授权，或取得第三方权利人的明确许可。
- 涉及可识别儿童的照片，应按园方制度和法律要求取得必要监护人同意；避免公开姓名、班级、定位等个人信息。

## 信息管理工作模板

本目录把岗位常见工作拆成可填写、可追踪的记录：

| 模板 | 用途 |
|---|---|
| 设备巡检记录 | 按设备类别检查状态，记录异常与复核结果 |
| 信息故障报修登记 | 建立工单编号，跟踪受理、处理、验收和关闭 |
| 活动影像采集与归档规范 | 从拍摄前授权核验到素材筛选、命名、归档 |
| 公众号稿件审核与隐私核对表 | 检查事实、文字、图片来源、个人信息和发布预览 |
| 月度信息工作交接清单 | 汇总账号权限、设备、备份、宣传资料和未完成事项 |

模板中的数据为空白或虚构示例；不含真实儿童资料、园所账号、密码或个人信息。真实工作中应按园所制度和审批流程执行。

## 作品集后续真实交付方向

- 活动摄影：本人拍摄的园所环境、活动布置、教具、成人示范及获得授权的活动照片。
- 公众号图文：真实活动资料、中文标题与正文、头图、图文排版和手机预览。
- 短视频：真实授权素材、分镜脚本、剪辑工程、字幕和封面。
- 信息管理：素材登记与备份、设备资产台账、维修工单、Excel月报和发布审核记录。

## 本地验收

媒体与文档资源以实际文件为准。可运行自动化检查：

python 09_验收测试/run_tests.py
python 09_验收测试/run_tests.py --json

## 安装与运行

视频生成环境：Python 3.10+、Pillow、FFmpeg。

```bash
pip install Pillow
python 03_宣传视频/视频生成脚本.py
python 09_验收测试/run_tests.py
```

视频生成脚本会在 `03_宣传视频/成片/` 输出三条 MP4；当前高画质成片作为本次对话独立文件交付，仓库保存可复现脚本与分镜说明。
