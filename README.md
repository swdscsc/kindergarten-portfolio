## 项目定位

本仓库围绕幼儿园集团信息管理员的工作场景，展示园所宣传内容策划、中文公众号编辑、摄影与短视频流程、素材归档、信息化办公支持等能力。

当前网页已调整为**中国幼儿园行业案例研究型作品集**：以国内园所、教育部门和教育媒体公开报道为研究样本，链接原文供查看真实图片和内容，不擅自复制第三方照片作为个人作品。

## 重要真实性说明

- 行业案例来自公开报道，仅用于学习分析；不代表本人参与过这些园所活动。
- 第三方报道中的图片、文字版权归原权利人。公开可访问不等于允许下载、修改、转载或用于个人作品集。
- 本轮新增的原创模拟视觉、宣传物料和程序化视频是作品集核心展示内容，均明确标注为模拟演示，不得声称为真实园所实拍。
- 正式摄影作品需要本人拍摄并取得必要授权，或取得第三方权利人的明确许可。
- 涉及可识别儿童的照片，应按园方制度和法律要求取得必要监护人同意；避免公开姓名、班级、定位等个人信息。

## 本地验收

媒体与文档资源以实际文件为准。可运行自动化检查：

```bash
python 09_验收测试/run_tests.py
python 09_验收测试/run_tests.py --json
```

不要把历史测试记录当成当前验收结果；以本地实际运行输出为准。


## 安装与运行

视频生成环境：Python 3.10+、Pillow、FFmpeg。

```bash
pip install Pillow
python 03_宣传视频/视频生成脚本.py
python 09_验收测试/run_tests.py
```

视频生成脚本会在 `03_宣传视频/成片/` 输出三条 MP4；当前高画质成片作为本次对话独立文件交付，仓库保存可复现脚本与分镜说明。
